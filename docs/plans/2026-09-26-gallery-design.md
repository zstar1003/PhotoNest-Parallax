# PhotoNest Parallax

以用户指定的 ArknightsParallaxCarousel 为交互参考：背景、主图、标题分别进行不同幅度的鼠标视差运动；切换主图时淡入缩放，文字平移。风格采用暗绿灰摄影展廊、灰绿强调色、窄体编号与中文标题。

使用纯 HTML/CSS/JavaScript，部署 GitHub Pages main 根目录。照片数据同步自 PhotoNest/gallery.json；缩略图在新仓库本地保存，原图按需跳转打开。全部照片可按城市筛选，保留标题、地点、分辨率。手机支持滑动、桌面支持键盘，尊重 reduced motion。

验证数据与文件一一对应、桌面与手机布局、轮播首尾、筛选、缩略图、灯箱、自动播放，以及部署后 HTTP 和图片加载。
